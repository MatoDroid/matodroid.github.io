# Guma ZAPPAR

Webový nástroj na čistenie a úpravu čiar ZAPPAR a hraníc parcier C (Spišská Nová Ves): guma, výber (dvojklik = celá plocha), kreslenie, posun, zlúčenie bodov, export .osm / GeoJSON.

Dáta (zašifrované heslom, AES-GCM; dešifrujú sa v prehliadači): parcely C z INSPIRE WFS ÚGKK SR (CC BY 4.0), ZAPPAR vektorizovaný z WMS ÚGKK SR (približný, len na porovnanie a úpravu, nie na priamy import do OSM bez súhlasu ÚGKK).
Lokálne ortofoto mesta (`orto/`) a ukladanie na server fungujú len pri lokálnom spustení (`serve_gumu.py`); na GitHub Pages sa úpravy ukladajú stiahnutím súboru.
