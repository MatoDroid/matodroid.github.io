YT prepisy

Stiahnite prepisy (titulky) z YouTube do súboru alebo do schránky. Zvládne aj viac videí naraz a celé playlisty. Všetko beží vo vašom prehliadači.

1. Odkazy na videá alebo playlisty

Akceptuje aj samotné ID videa (11 znakov), youtu.be, /shorts/, /live/, /embed/ a odkazy na playlisty. Odkazy môžu byť oddelené aj čiarkou alebo medzerou.

2. Nastavenia

Poradie podľa priority, oddelené čiarkou. Prázdne = prvé dostupné.
Použije automatický preklad titulkov na YouTube.
Viac = rýchlejšie, ale vyššie riziko limitov proxy.
Rozšírené – vlastná CORS proxy

YouTube neposiela CORS hlavičky, preto sa požiadavky posielajú cez verejné proxy servery. Tie bývajú preťažené. Ak máte vlastnú proxy, zadajte ju sem – použije sa prednostne.

{url} sa nahradí adresou (kódovanou). Ak {url} nepoužijete, adresa sa pripojí na koniec.

Príklad Cloudflare Worker (zdarma, spoľahlivejší než verejné proxy):

export default {
  async fetch(req) {
    const target = new URL(req.url).searchParams.get("url");
    if (!target) return new Response("chyba url", { status: 400 });
    const r = await fetch(target, {
      headers: { "user-agent": "Mozilla/5.0", "accept-language": "sk,en;q=0.8" }
    });
    const h = new Headers(r.headers);
    h.set("access-control-allow-origin", "*");
    return new Response(r.body, { status: r.status, headers: h });
  }
}

4. Výstup

Ako to funguje / riešenie problémov

Video nemá prepis – čo s tým?
Prepis existuje len ak má video titulky (vlastné alebo automatické). Ak autor titulky vypol, prepis sa získať nedá. Skúste tiež zapnúť Povoliť automatické titulky a vyprázdniť pole s preferovanými jazykmi.
Hlásenie „nepodarilo sa načítať cez proxy“
Verejné CORS proxy majú limity a občas vypadnú. Skúste to o chvíľu znova (tlačidlo Zopakovať neúspešné), znížte počet súčasne spracovaných videí na 1, alebo si nasaďte vlastný Cloudflare Worker podľa návodu v nastaveniach.
Koľko videí z playlistu sa načíta?
Načíta sa prvá stránka playlistu, čo je zvyčajne prvých 100 videí. Pri dlhších playlistoch pridajte zvyšné videá ručne.
Odchádzajú moje dáta niekam?
Aplikácia beží celá v prehliadači a nemá vlastný server. Požiadavky na YouTube však prechádzajú cez zvolenú verejnú CORS proxy – tá vidí, ktoré videá sťahujete. Nastavenia sa ukladajú len lokálne do prehliadača.
